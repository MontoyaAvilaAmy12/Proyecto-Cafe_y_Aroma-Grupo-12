# Proyecto-Cafe_y_Aroma-Grupo-12
Sistema de Gestión y Control de Ventas para Cafetería Café &amp; Aroma

## Descripción del Proyecto
Sistema desarrollado en Java bajo el paradigma de Programación Orientada a Objetos (POO) para la gestión de productos, inventarios, pedidos y control de ventas de la cafetería Café & Aroma[cite: 2].

## Tecnologías Utilizadas
* Java SE (JDK 17 o superior)
* Apache NetBeans IDE
* Git / GitHub[cite: 1]

## Estructura del Repositorio
* `src/`: Código fuente de la aplicación Java (`Producto`, `Bebida`, `Alimento`, `Servicio`, `Pedido`, `DetallePedido`, `Inventario`, `GestorVentas`, `Proyecto_Cafeteria_G12`).
* UML Cafe&Aroma.drawio.png

## Instrucciones de Ejecución
1. Clonar o descargar el repositorio en tu equipo[cite: 1].
2. Abrir el proyecto en Apache NetBeans IDE[cite: 1].
3. Compilar y ejecutar la clase principal `Proyecto_Cafeteria_G12.java`[cite: 1].
